# Great Economic Thinkers and their Ideas

An interactive website exploring how economic thinkers answered the three questions every economy faces: **what will we make, how will we make it, and how will we share it?**

## Case files

| Case | Thinker | Game |
|---|---|---|
| 001 | Before Adam Smith (mercantilists, individualists, Physiocrats) | The Haunting of Mercantile Manor |
| 002 | Adam Smith | Invisible Hand |
| 003 | Thomas Robert Malthus | The Malthus Trail |
| 004 | David Ricardo | The Stationary State |
| 005 | Jeremy Bentham, J.B. Say & Nassau Senior | coming soon |

Plus **The Line-Up** (compare thinkers side by side) and **Who Said It?** (a quote quiz).

Interpretations follow E.K. Hunt & Mark Lautzenheiser, *History of Economic Thought: A Critical Perspective* (2011).

Website created by Maria Petrolia using Claude Code

## Running it on your own computer

Double-click `start-site.bat`, or run:

```
python serve.py
```

Then open http://localhost:8080.

## Publishing an update

Double-click `publish.bat` (or run it from a terminal). It saves every change and pushes it to GitHub; the live site updates within a minute or two.
